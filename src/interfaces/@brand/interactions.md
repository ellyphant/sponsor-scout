# Product Interaction Texture

Motion is quick, precise and settled. It helps Elly follow a result from research into a review packet, but never invents activity or celebrates a send before the service reports its outcome. The main web and outreach specs take precedence when a visual example implies a different action or state.

~~~
Final designer tokens: ease-out cubic-bezier(0.16,1,0.3,1); ease-std cubic-bezier(0.4,0,0.2,1); ease-in cubic-bezier(0.4,0,1,1). Hover/focus 120ms, press 80ms, state crossfade 200ms, panels/drawers 240ms, new activity/counters 400ms, login release 360ms. Mobile sheet spring if used: stiffness 520, damping 40. Reduced motion removes transforms/staggers/count-ups, limits opacity fades to 100ms and makes glow static.

Keyboard focus: 0 0 0 2px rgba(255,176,32,.5), 0 0 0 5px rgba(255,176,32,.08). Row hover raises full surface to Slate and reveals an amber arrow without a colored edge border. Primary hover becomes #FFC24D; press scale .98. Glow can change discretely but shadow blur/spread is not animated. Citation borders warm to rgba(255,176,32,.4).

Skeletons mirror final geometry: #161309 with opacity .6 to .85 in 1.8s, no shimmer. Empty states use a reticle/icon, a useful line and one primary action. Auth code entry is not green until verification succeeds. Login enters fade/rise 8px over 320ms; state switches 200ms; verifying boxes stay amber; errors shake ±4px, 3 cycles/300ms; successful code boxes may settle 1 -> 1.04 -> 1 over 180ms and release in 360ms.

Run launch replaces the idle region in place over 200ms; readout/activity entrance 280ms. Findings and citations arrive together, complete. THIS RUN result rows become queue links only when saved. Completed runs retain frozen elapsed time and an honest summary. Missing providers show real errors, never a fabricated retry. Scroll-up releases auto-follow and shows a jump-to-latest pill; jump motion 300ms. Shared sponsor-name/score transitions can use Motion layoutId over 240ms; the light letter can fade in 80ms behind the case. Do not resize the streaming column.

Editing stays in the letter's visual language but follows explicit Save/Cancel from the approved spec, not blur-autosave. Recipient format feedback does not claim deliverability. Rejection captures an optional reason in a sheet/popover, not an expanding layout; it is feedback, not automatic training. Sample review always requires a backend guard even though it makes no email call. Its muted success says no mail was sent. Test and live acceptance use accurate acceptance copy, not premature Sent/Delivered. No sample-to-live conversion control.

Keyboard shortcuts outside form controls: R opens run controls, J/K changes list selection, Enter opens it, A opens recipient review (never dispatches), E edits, X opens rejection confirmation, Escape dismisses. Buttons retain accessible labels/hit targets; shortcuts never bypass a confirmation.

Mobile tabs use instant navigation with a 120ms opacity change rather than a slide carousel. Full-height review sheets can hide duplicated navigation chrome. Safe-area padding and keyboard-safe scrolling keep actions available. Events show a read-only CoHost label and no edit affordance; asks are verbatim quotes. No funding progress indicators.
~~~
